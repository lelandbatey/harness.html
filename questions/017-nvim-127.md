# nvim exited 127 in the subagent environment

- status: done

- answered: 2026-11-19

## Question

nvim exited 127 in the subagent environment

## Answer

127 = command not found: the default `editor` setting was `"nvim"`, but on this machine Neovim is
only on PATH as `vim` (`~/bin/vim` symlink), so `execvpe("nvim")` failed in the pty child.

Fix: the `editor` setting now defaults to empty, and `pty_ws.resolve_editor` uses the first of
setting, `$EDITOR`, `nano`, `pico`, `vi` whose program is on PATH. If none is, the in-page terminal
shows "no editor found on PATH (tried: …)" and exits 127 without spawning anything.
